# Multimedia Project: Air Pollution Data Explorer

This repository contains a small multimedia project for exploring and visualizing global air pollution data. It combines data analysis and infographic assets to help communicate environmental and public health findings clearly.

## What’s Included

- `eda.ipynb`: A Jupyter notebook with exploratory data analysis steps, charts, and observations.
- `global_air _pollution_dataset.csv`: The main dataset used for analysis.
- `Infographic Design Suite_Folder/`: A folder containing infographic assets and reference images for design work.

## Project Purpose

The goal of this project is to:
- analyze air pollution trends,
- identify interesting patterns in environmental data,
- and support those insights with simple visuals or infographic-ready assets.

This makes it easier to turn data into more engaging, human-friendly content for presentations, reports, or educational materials.

## How to Use

1. Open `eda.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
2. Run the notebook cells to explore the dataset and view charts.
3. Review the visualization ideas and use the design assets in `Infographic Design Suite_Folder/` if you want to create an infographic or presentation.

## Notes

- The project is intentionally simple and easy to extend.
- You can build on this by adding more data visualizations, refining the notebook analysis, or creating polished infographic layouts.

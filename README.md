# Multimedia Project

This workspace contains a small multimedia data project focused on exploring air pollution data.

## What is here

- `eda.ipynb`: A Jupyter notebook for exploratory data analysis.
- `global_air _pollution_dataset.csv`: The main dataset used for analysis.
- `Infographic Design Suite_Folder/`: A folder holding design assets and reference images.

## Why it exists

The goal is to analyze environmental data and use simple visuals or design assets to help explain findings in a more human-friendly way.

## How to use it

1. Open `eda.ipynb` in Jupyter or VS Code.
2. Run the notebook cells to explore the dataset.
3. Use the design assets if you want to create an infographic or presentation from the results.

## Notes

The project is intentionally simple and meant to be easy to understand and expand.
